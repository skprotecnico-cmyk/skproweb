# Tiendas Tuoffice SKPRO - Catalogo completo

Proyecto Vite + React listo para publicar en Netlify o Vercel.

## Publicar en Netlify
1. Sube esta carpeta a GitHub.
2. En Netlify, importa el repositorio.
3. Build command: `npm run build`
4. Publish directory: `dist`

## Desarrollo local
```bash
npm install
npm run dev
```

## Estructura importante
- `public/logo.jpg`
- `public/productos/`
- `src/App.jsx`

Las imagenes de productos fueron extraidas del PDF del catalogo suministrado por el usuario.
